# Changelog

All notable changes to this project will be documented in this file.

## [3.0.0] - 2026-10-18
### Added
- Comprehensive architectural documentation (`docs/`) including Data Contract, Metrics, Architecture, Methodology, and Testing guides.
- Standardized TypeScript test harness (`src/test_harness.ts`) for deterministic metric validation.
- Unified Composer Library with 7 historical/liturgical master cores.
- Dual representation of voice counts (`voice_counts` and `voice_list`) in the generated JSON passport.

### Fixed
- Empty ensemble calculation safety in React and Python generators.
- Strict type checking compliance across all modules.
